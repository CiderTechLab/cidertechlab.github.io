当サイトは私、S.Kのプロフィール、スキル、経歴、並びに制作したポートフォリオ作品の紹介サイトです。

# 設計・実装のポイント

## モバイルファーストのレスポンシブデザイン

CSSのメディアクエリを利用し、モバイル環境を最優先（モバイルファースト）でデザインすることで、多様な画面サイズに対応できるサイトを実現しました。スマートフォンやタブレット、PCなど様々なデバイスで閲覧が可能です。

## 保守性・拡張性

サイト制作に終わりはありません。コンポーネント化、モジュール化を行い、将来の修正や機能追加が容易な構造を心がけました。

## Vanilla実装で基礎力強化、モダンな開発手法にも挑戦

メインサイトはVanillaのCSS/JavaScriptで実装し、基礎力の向上を目指しました。一方、ポートフォリオ作品の一部ではTypeScriptやTailwind CSSやReactなどのフレームワークも使用し、モダンな開発手法にも挑戦しました。

## GitHub Wikiでドキュメント化

設計書やサイトマップなどのドキュメントはGitHub Wikiにまとめ、プロジェクトの全体像を把握しやすくしました。これにより、保守や拡張がスムーズに行えるようにしています。
